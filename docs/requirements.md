# Climate Control — вариант 3
Назначение: приём показаний датчиков кампуса. Управление физическими исполнительными устройствами не реализуется.
R01 Подлинность и целостность: HMAC-SHA256 над точными байтами тела и контекстом запроса.
R02 Свежесть: заголовок времени в пределах ±120 секунд, nonce не используется повторно.
R03 Диапазоны: температура -40..85 °C, влажность 0..100 %, sequence 1..1000000000.
R04 Доступ: зарегистрированный sensorId совпадает с субъектом, scope telemetry:write обязателен.
R05 Уникальность: пара sensorId/sequence не записывается повторно.
R06 Защита ресурса: тело ≤4096 байт, не более 4 запросов датчика в минуту в учебном стенде.
R07 Наблюдаемость: решение в журнале без ключей, подписи и исходного тела.
R08 Данные: параметризованные запросы EF Core, постоянная БД SQLite для самостоятельного запуска.
